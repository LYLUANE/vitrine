Por dentro do agente de vendas

A demo simula o raciocínio com regras para rodar no navegador. Em produção, quem decide qual ferramenta usar é um modelo de linguagem (ex.: Claude). O resto é o mesmo: as ferramentas, as travas no código, os logs e a passagem para uma pessoa.

Um turno, passo a passo

É o mesmo ciclo que o painel de bastidores da demo mostra, só que com o modelo no lugar das regras.

  1. Chega a mensagemO orquestrador recebe o webhook do WhatsApp e junta o histórico daquele cliente.
  2. O modelo lêRecebe a conversa, as regras da loja e a lista de ferramentas com o que cada uma faz.
  3. Pede ferramentasDevolve qual ferramenta chamar e com quais argumentos, em JSON.
  4. O código executaO orquestrador valida, aplica as travas, consulta o ERP e devolve o resultado.
  5. RespondeCom os dados reais em mãos, o modelo escreve a resposta. Tudo vai para o log.

Travas, logs e avaliação

Travas no código, não só no prompt

  • Desconto: a ferramenta gerar_orcamento recusa percentual acima do teto, mesmo que o modelo peça.
  • Catálogo: preço e prazo só saem de consultar_estoque. Busca vazia vira "não temos".
  • Fechamento: registrar_pedido exige o "sim" do cliente gravado no turno anterior.
  • Reclamação: palavras de insatisfação disparam transferir_para_humano antes de qualquer resposta.

Logs e avaliação de respostas

  • Cada turno grava a mensagem, as ferramentas, os argumentos, os resultados e a resposta, como no painel da demo.
  • Um conjunto de conversas de teste (pedido comum, desconto, produto inexistente, reclamação, frase confusa) roda antes de cada mudança de prompt ou de regra.
  • Cada resposta recebe nota: usou a ferramenta certa? respeitou a trava? o valor bate com o ERP?
  • Conversas transferidas para pessoas viram novos casos de teste.

def responder(historico):
    while True:
        resposta = client.messages.create(
            model="claude-opus-5-5",
            max_tokens=16000,
            system=PROMPT_DA_LOJA,
            tools=TOOLS,
            output_config={"effort": "low"},

            return "".join(b.text for b in resposta.content if b.type == "text")

        for bloco in resposta.content:
            if bloco.type == "tool_use":

        historico.append({"role": "user", "content": resultados})

O que vai na versão real

OrquestradorFluxo no n8n ou servidor Node/Python com o ciclo de ferramentas e o histórico por cliente.
WhatsApp oficialNúmero na API oficial do WhatsApp (Cloud API), com webhook e modelos de mensagem aprovados.
ERP ou planilhaFerramentas ligadas ao estoque, preços e pedidos do seu sistema ou da sua planilha.
Painel de conversasA equipe vê tudo, assume a conversa e devolve para o agente.
Logs e testesRegistro de cada passo e conjunto de conversas de teste rodado antes de mudanças.
Travas comerciaisTeto de desconto, confirmação de pedido e regras de transferência definidas com você.
